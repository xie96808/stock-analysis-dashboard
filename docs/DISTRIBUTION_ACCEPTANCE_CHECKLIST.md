# 成交量 / 筹码分布验收单

> 功能分支：`feat/mutually-exclusive-distributions`  
> 基线：`main@f13ab8b`  
> 状态：等待用户界面验收

## A. 互斥与工具栏

- [ ] 工具栏显示“分布：成交量 / 筹码”的互斥选择器；
- [ ] 选择“成交量”时页面不存在筹码分布面板；
- [ ] 选择“筹码”时页面不存在成交量分布面板；
- [ ] “隐藏”后两种分布都消失，再次点击恢复上一次选择；
- [ ] 纯净模式临时隐藏分布，退出后恢复；
- [ ] 切换分布不会清空画线或改变当前K线周期。

## B. 成交量分布

- [ ] 保留覆盖/停靠布局；
- [ ] 保留宽度调节；
- [ ] 未画锚定区间时标题为“可视区成交量分布”；
- [ ] 存在锚定区间时标题为“锚定区间成交量分布”；
- [ ] 滚轮缩放或横向平移后，柱形、POC、VAH、VAL随统计区间重算。

## C. 筹码分布

- [ ] 标题明确显示“筹码分布 · 截至 YYYY-MM-DD”；
- [ ] 获利筹码为红色、套牢筹码为蓝色，并有图例；
- [ ] 显示现价线、平均成本线、收盘获利比例；
- [ ] 显示70%/90%筹码区间及集中度；
- [ ] “筹码指标”卡可通过顶部拖动区移动，且始终限制在筹码面板内；
- [ ] 点击指标卡右上角关闭按钮后，筹码柱不受影响且标题区出现“显示指标”；
- [ ] 点击“显示指标”可恢复指标卡及其上次停留位置；
- [ ] 筹码面板缓冲区延伸至图表底部，指标卡主体退出价格区且筹码价格坐标不被压缩；
- [ ] 显示“模型估算，不代表真实账户持仓”；
- [ ] A股正常显示“流通盘换手模型”，换手数据缺失时明确显示降级估算；
- [ ] 滚轮缩放和横向拖动不会改变“截至日期”与筹码指标；
- [ ] 普通、Log和百分比坐标下，筹码柱仍与价格轴对齐；
- [ ] 非最新历史日期显示“恢复最新”，点击后回到最新交易日。

## D. 日K日期选择

- [ ] 选择工具下左键点击日K，只弹出操作菜单，不自动进入分时；
- [ ] 菜单同时提供“查看当日分时图”和“查看截至当日筹码”；
- [ ] 选择“查看截至当日筹码”后切换到筹码模式，截止日期等于该K线日期；
- [ ] 选择“查看截至当日筹码”只更新筹码覆盖层，主图缩放与横向可视区保持不变；
- [ ] 选择“查看当日分时图”后仍可通过“返回日K”退出；
- [ ] 分钟K、周K、月K不提供上述日K操作菜单；
- [ ] 画线工具启用时点击K线不弹出菜单。

## E. 市场与状态保存

- [ ] A股支持两种分布；
- [ ] 港股保留成交量分布，选择筹码时给出清晰说明；
- [ ] 刷新页面后恢复上次分布类型、布局和宽度；
- [ ] 新研究记录包含分布模式、布局、宽度和筹码截止日期；
- [ ] 加载旧记录时可以迁移旧版 `profileMode/chipVisible` 状态。
