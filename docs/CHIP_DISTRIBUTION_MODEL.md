# 成交量分布与筹码分布

## 两种模式

看板中的“成交量分布”和“筹码分布”使用同一个右侧显示区域，并且互斥：

- **成交量分布**：统计当前可视区或最后一个锚定区间中，各价格档发生的成交量。缩放或平移会重算；输出 POC、VAH、VAL。
- **筹码分布**：估算截至某个交易日仍留存在市场中的筹码成本。缩放或平移不改变基准日；输出平均成本、收盘获利比例、70%/90%筹码区间与集中度。

工具栏中的“成交量 / 筹码”分段按钮负责切换，旁边的“隐藏”按钮只控制可见性。纯净模式会临时隐藏当前分布，退出纯净模式后恢复原选择。

## 筹码递推模型

设 `C[t][p]` 为第 `t` 个交易日结束后，价格档 `p` 的筹码权重，`turnover[t]` 为当天换手率，`D[t][p]` 为当天新成交成本分布：

```text
C[t][p] = C[t-1][p] × (1 - turnover[t]) + D[t][p] × turnover[t]
```

每个交易日完成后重新归一化，全部价格档权重之和保持为 `1`。

当行情源没有直接给出历史换手率时，A股日线使用：

```text
turnover = daily_volume_shares / current_circulating_shares
```

该口径能使用公开免费数据稳定计算，但历史流通股本发生变化时仍是估算。因此界面保留“模型估算，不代表真实账户持仓”的说明。

若换手率与流通股本均缺失，计算器会使用明确标记的成交量代理；界面显示“降级估算”，不会把代理值伪装成真实换手率。

## 单日成本分配

免费日线通常只有 OHLCV：

1. 在最低价到最高价之间建立可用价格档；
2. 有成交额时以 `amount / volume` 作为日均成交价；
3. 无成交额时以 `(high + low + close) / 3` 作为中心；
4. 使用“18%均匀分布 + 82%以均价为中心的三角分布”；
5. 再按当日换手率加入递推模型。

这一分配方式是可解释的日线近似，不声称复现任何商业软件的私有参数。后续取得完整分钟历史后，可以把 `D[t][p]` 替换为分钟成交量按价格聚合，其他递推与指标无需改变。

## 指标

- **平均成本**：`sum(price × weight)`；
- **收盘获利比例**：成本不高于基准日收盘价的筹码权重；
- **70%筹码区间**：第15%到第85%加权分位；
- **90%筹码区间**：第5%到第95%加权分位；
- **集中度**：`(high - low) / (high + low)`；
- **筹码峰值**：权重最大的价格档。

## 日期行为

- 默认基准日为最新可用A股交易日；
- 在日K选择工具下点击K线，会出现“查看当日分时图”和“查看截至当日筹码”两个独立操作；
- 只有用户选择后者才改变筹码基准日；
- “恢复最新”回到最新交易日；
- 普通滚轮缩放、横向拖动与画线不改变筹码基准日；
- 非日K周期可以显示既有筹码基准日，但只在日K提供历史日期选择。

## 市场边界

- A股：启用成交量分布和筹码分布；
- 港股：当前启用成交量分布；筹码分布等待免费数据源的流通盘与公司行为口径验证。
