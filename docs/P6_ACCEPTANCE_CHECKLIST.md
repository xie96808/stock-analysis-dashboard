# P6 用户验收单

> 验收版本：`0.7.0`

- [ ] 保存记录会冻结Markdown、结构化字段、画线、指标、坐标状态、数据截止时间与2×PNG。
- [ ] 同一天可保存任意多条独立记录，日历按日期检索完整。
- [ ] 正式数据保存在本机SQLite，不依赖账号或云服务。
- [ ] “追加版本”生成v2/v3，v1原文、画线和PNG不被覆盖。
- [ ] 快照弹窗可切换全部revision，并左右对比相邻版本。
- [ ] 历史快照可只读查看、复制画线、替换工作区。
- [ ] “以当日视角查看”截断记录数据截止点之后的K线。
- [ ] 主工作区删除画线不会改变历史revision快照。
- [ ] 删除先进入回收站，可恢复；永久删除需要二次点击确认。
- [ ] 单条导出包含`record.md/chart.png/drawings.json/chart-state.json/indicators.json`。
- [ ] 项目ZIP包含版本化manifest、records、附件与SHA-256校验。
- [ ] 从项目ZIP恢复会校验schema和哈希，重复导入不会复制已有记录。
- [ ] 每日SQLite备份自动生成并轮换保留最近30份。
- [ ] Markdown标题、列表、粗体等在时间线与快照中渲染。
