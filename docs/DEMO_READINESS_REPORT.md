## 分级原则

等级按“演示失败时对核心价值的影响”划分，而不是按历史开发批次划分。

### P0：核心闭环，任何一项失败都应中止演示

1. A 股、ETF、北交所、港股代码/名称本地联想与标的切换；
2. 日/周/月 K 与 1/5/15/30/60 分钟周期；
3. 普通、Log、百分比价格坐标及缩放、平移、适应画面；
4. MA/EMA、VOL、MACD 主副图同步；
5. 水平线、趋势线、射线、矩形、文本、自由画笔、测量，及拖动、撤销、重做、清除；
6. 成交量分布与筹码分布互斥、历史筹码日期、指标卡；
7. 日 K 单击菜单进入分时、单一返回入口；
8. Markdown 研究日志、同日多条、不可覆盖 revision、日期检索、回收站；
9. 手动刷新时保持画布和画线，不出现空白图或 crash。

### P1：专业分析闭环，失败不会破坏主图但会明显削弱产品完整性

1. 本地自选、复盘状态与批量切换；
2. 条件提醒；
3. 日线策略回测；
4. 模拟交易账本；
5. 腾讯主源、Yahoo 备用源、缓存和质量提示；
6. 白天/黑夜模式、字号与 K 线配色；
7. A/H 市场能力边界（港股禁用 A 股筹码模型）。

### P2：效率、迁移与展示增强

1. 命名工作区与纯净模式；
2. 高清 PNG；
3. 研究项目 ZIP 导出、校验、导入恢复；
4. 每日 SQLite 备份；
5. 数据源详情、缓存新鲜度和自动 15 秒刷新调度；
6. 标的搜索本地索引、请求合并和过期缓存后台刷新。

### P3：后续亮点候选

组合级回测、参数寻优、策略脚本、复盘播放、横截面扫描、事件日历、PWA/离线模式、可选跨设备同步与团队协作。

## 本轮发现并修复

**项目 ZIP 导出在网页部署场景只显示服务器绝对路径。**这在本机看似可用，但网站用户无法访问服务器文件系统。现在后端同时返回受约束的下载 URL 和文件名；前端获取 ZIP Blob 后触发浏览器下载。新增前后端回归测试，下载接口实际返回 HTTP 200。
