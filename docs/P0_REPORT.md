## 交付范围

P0 用于验证界面方向和关键坐标能力，不连接正式行情后端。当前使用确定性本地样例数据，重点展示：

- 接近 TradingView 的白底、细网格、大画布布局；
- 最新 K 线右侧延伸至 2027 年的未来空白；
- 普通价格轴与 Log 价格轴切换；
- K 线、VOL、MACD 三面板共用时间轴；
- 可视区成交量分布，初始画布不预置价格线、趋势线或分析文字；
- 大字号横纵坐标和 Profile 标签；
- 左侧画图工具、悬浮名称提示、周期、复权和命名工作区入口；
- 右侧日历检索、Markdown 记录和历史加载/删除入口；
- 点击任意日 K 进入对应日期分时图，并支持返回日线。
