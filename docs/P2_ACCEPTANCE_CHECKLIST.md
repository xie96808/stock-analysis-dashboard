# P2 用户验收单

> 验收版本：`0.3.0`  
> P2目标：真实A/H股行情、周期、复权、缓存与数据状态

## 1. 代码与行情

- [ ] 输入 `001280` 并提交，识别为 `SZSE`，显示中国铀业真实日线。
- [ ] 输入 `600000.SH`，识别为 `SSE`。
- [ ] 输入 `00700.HK` 或 `700`，识别为 `HKEX`，显示腾讯控股行情。
- [ ] 无效代码显示读取失败提示，现有画布不被清空。
- [ ] 行情栏明确显示延时/缓存/降级状态和数据日期。

## 2. 周期与复权

- [ ] `1/5/15/30/60分、日K、周K、月K` 均会真实切换数据，不再显示P2占位提示。
- [ ] 日/周/月按实际交易bar聚合，节假日、停牌日不补空K线。
- [ ] 前复权、不复权、后复权均能切换。
- [ ] A股首次打开默认前复权。
- [ ] 每个标的会记住用户最后一次选择的复权方式。
- [ ] 分钟K明确采用不复权数据，切换周期不会造成页面崩溃。

## 3. 日K与分时

- [ ] 点击日K可进入该交易日的5分钟分时。
- [ ] 行情源有该日期分钟数据时标记“真实5分钟行情”。
- [ ] 免费源不含该历史日期时使用本地拟合预览并明确标记。
- [ ] 可返回日K，上海时区标签正确。

## 4. 缓存与可靠性

- [ ] 相同请求在缓存有效期内显示“缓存”。
- [ ] 刷新数据会按时间键合并历史与新增bar。
- [ ] A股日线缓存4小时，分钟缓存2分钟。
- [ ] API不可用时，`001280` 自动回退到确定性样例，Log/缩放等交互仍可用。
- [ ] `npm run build` 通过。
- [ ] `npm run test:backend` 全部通过。
- [ ] 浏览器控制台无新增错误或警告。

## 5. 验收结论

- [ ] **通过**：以上范围通过，允许合并并创建 `v0.3.0-p2`。
- [ ] **有条件通过**：记录免费源的历史分钟数据限制后进入P3。
- [ ] **不通过**：保留分支并修复。
