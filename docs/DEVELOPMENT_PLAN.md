# A/H 股画线分析看板开发计划

> 状态：P0–P7全部完成；第一版 `v1.0.0` 已通过自动与浏览器验收
> 建立日期：2026-08-09  
> 项目目录：`stock-analysis-dashboard/`

## 1. 产品目标

建立一个桌面端优先的 A 股/港股技术分析看板。它应接近 TradingView 的视觉语言和操作方式，但针对本项目重点加强：

- 宽阔、干净的 K 线画布；
- 精确、可持久化的画线系统；
- 可以任意拉长、压缩和向未来延伸的横坐标；
- 大字号日期、价格、筹码价格与指标标签；
- 真实日期横轴与普通/Log 价格纵轴；
- VOL、MACD、Volume Profile 与筹码成本模型；
- A 股、港股统一的代码输入和周期切换。

### 1.1 第一版明确包含

- 股票代码搜索与市场自动识别；
- 1/5/15/30/60 分钟，日/周/月周期；
- 不复权、前复权、后复权；
- A 股默认前复权；
- K 线、成交量、MA/EMA、MACD；
- 十字光标、框选缩放、滚轮/触控板缩放、拖动平移；
- 水平线、趋势线、射线、矩形价格区间；
- 可视区 Volume Profile 与锚定区间 Volume Profile；
- POC、Value Area High、Value Area Low；
- 线性价格轴、对数价格轴、百分比价格轴；
- 图形和布局本地保存；
- 按日期保存预测、分析记录及当时的图形快照；
- 导出高清截图。

### 1.3 已确认的运行与数据边界

- 形态：本机 Web 应用，浏览器访问本地服务；
- 用户：单用户，不建设登录和账户系统；
- 数据时效：面向傍晚复盘，不追求交易级完全实时；
- A 股默认前复权，用户可以切换不复权和后复权；
- 港股允许使用有延时的免费行情，并明确显示数据时间；
- 第一版研究记录只关联一个个股；多标的/大盘综合记录留作后续扩展；
- 自动备份每日一次，默认保留最近 30 份，另有手动完整导出。

### 1.2 第一版暂不包含

- 券商下单；
- Pine Script 兼容层；
- 多人协作；
- Level-2 十档盘口；
- 把筹码模型包装成真实投资者持仓数据；
- 移动端竖屏的完整画线体验。

## 2. 从参考图提取的设计结论

### 2.1 保留 TradingView 式特征

1. 主图占据绝大多数可用面积。
2. 时间轴可大范围压缩、展开，并允许最新 K 线右侧存在大量未来空白。
3. 价格轴位于最右侧，标签与水平参考线直接对齐。
4. Volume Profile 贴近价格轴显示，不创建割裂的独立信息卡片。
5. VOL、MACD 等副图共享同一时间轴和十字光标。
6. 画线对象直接存在于主画布中，可延伸到尚无行情数据的未来日期。
7. 顶部只显示必要的 OHLC、涨跌幅、成交量与当前代码信息。

### 2.2 避免同花顺截图中的问题

- 不固定占用四分之一画布展示筹码；
- 不默认叠加大量买卖点、数字序列和多空徽标；
- 不让均线、标记、指标标签同时遮挡 K 线；
- 不把成交量分布与筹码成本分布混为一项；
- 不以触控按钮为核心设计桌面画线工作流；
- 不牺牲纵轴刻度来换取侧边信息卡。

### 3.1 面板行为

- 左侧工具栏默认宽度控制在 44–52px，可折叠；
- Volume Profile 支持三种形态：覆盖、靠右停靠、隐藏；
- Profile 宽度可拖动，建议默认占主图宽度的 18%；
- VOL/MACD 面板高度可拖动，最小高度保证纵轴标签可读；
- 所有副图与主图共享时间范围、缩放、平移和十字光标；
- “纯净模式”一键隐藏指标、事件和非必要标签，只保留 K 线与画线。

## 4. 视觉与字号规范

### 4.1 视觉方向

- 背景：白色或极浅灰；
- 网格：低对比度中性灰，避免抢夺画线注意力；
- K 线：默认接近参考图的黑白方案，同时提供中国市场红涨绿跌方案；
- 画线：默认高饱和红、蓝、黑，线宽至少 1.5px；
- Profile：双向成交量使用粉红/青色，筹码成本另用红/蓝，避免语义混淆；
- 画布使用高 DPI Canvas，保证 Retina 屏文字和线条清晰。

### 4.2 字号下限

| 元素 | 默认字号 | 最小字号 |
|---|---:|---:|
| 顶部股票名称/最新价 | 18px | 17px |
| 顶部 OHLC/成交量 | 16px | 15px |
| 横轴日期 | 16px | 15px |
| 纵轴价格 | 16px | 15px |
| Profile 价格标签 | 15px | 14px |
| POC/VAH/VAL 标签 | 15px | 14px |
| 副图纵轴 | 15px | 14px |
| 工具按钮/提示 | 15px | 14px |

字号通过 CSS design tokens 集中配置，并提供“标准/大/特大”三档。加大字号时优先减少刻度数量，而不是压缩文字或互相覆盖。

## 5. 横坐标与时间轴

横轴采用 TradingView 式金融时间轴：已有 K 线按交易序列排列，周末和休市日不生成空 K 线；刻度始终显示真实日期或时间。横向缩放改变每根 K 线的像素间距，而不是对日期取 Log。

### 5.1 时间轴语义

- 日/周/月 K 按交易 bar 的逻辑序号等距排列；
- 分钟 K 按交易时段排列，午休和非交易时段不占用大量空白；
- 每根 bar 仍保存真实交易时间，用于十字光标、画线、日志和导出；
- 未来空白区根据市场交易日历生成逻辑坐标，并显示真实日期标签；
- 画线锚点始终保存为 `{timestamp, price}`，不保存屏幕像素；
- Profile 按当前可视时间范围重新计算。

### 5.2 时间轴交互

- 滚轮或双指：横向缩放；
- `Shift + 滚轮`：水平平移；
- 拖动横轴：只改变横向缩放；
- 双击横轴：恢复建议范围；
- 允许最新 K 线右侧保留 10%–80% 视口宽度的未来空白；
- 可输入明确的未来截止日期，例如将横轴延伸到六个月后。

## 6. 普通与 Log 价格轴

两张参考图的关键差异位于纵轴：普通坐标以相同价差等距，Log 坐标以相同涨跌比例等距。横轴日期不参与 Log 变换。

### 6.1 普通价格模式

```text
y_linear(p) = a × p + b
```

- 价格增加相同绝对值时，屏幕距离相同；
- 适合窄幅区间和短周期观察；
- 纵轴标签使用等价差刻度。

### 6.2 Log 价格模式

```text
y_log(p) = a × ln(p) + b,  p > 0
```

- 相同百分比涨跌对应相同屏幕距离；
- 更适合跨越较大价格范围的长期趋势分析；
- 纵轴标签继续显示真实价格，而不是 `ln(price)` 数值；
- 趋势线锚点仍保存真实日期与真实价格；
- 切换模式后端点语义不变，但线条视觉斜率会依照新坐标重新投影；
- Log 模式下 Profile 价格分箱按等 `Δln(price)` 或等屏幕高度划分，确保条形与价格轴严格对齐。

### 6.3 共同交互

- 普通价格、Log 价格、百分比变化一键切换；
- 自动缩放与手动锁定范围；
- 拖动价格轴改变纵向缩放；
- 双击恢复自动缩放；
- `Alt + 1`：普通价格；
- `Alt + 2`：Log 价格；
- `Alt + 3`：百分比；
- 当前价、画线价、POC、VAH、VAL 使用大字号彩色标签；
- 标签碰撞时采用分层避让，并用细引导线指向真实价格。

## 7. 画线系统

### 7.1 第一版工具

- 水平线；
- 趋势线；
- 向左/向右射线；
- 平行通道；
- 矩形区间；
- 日期区间；
- 价格区间；
- 文本批注；
- 自由画笔；
- 半透明荧光笔；
- 对象橡皮擦与笔画橡皮擦。

### 7.2 精度与操作

- 磁吸关闭、弱吸附、强吸附三档；
- 吸附目标：开、高、低、收、最近成交价、POC/VAH/VAL；
- 锚点支持直接输入日期和价格；
- 支持选择、移动、复制、锁定、隐藏、删除；
- 支持撤销/重做；
- 支持线条延伸、颜色、线型、线宽、标签位置；
- 自由画笔支持颜色、粗细、透明度、平滑度和笔迹简化；
- 画笔路径保存为日期/价格坐标中的矢量点，缩放、平移和切换普通/Log 价格轴时保持金融位置；
- 支持鼠标、触控板、触控笔 Pointer Events；硬件提供压力值时可选择启用压感；
- 对象橡皮擦删除完整图形，笔画橡皮擦可切断自由画笔路径；
- 可设置仅在哪些周期显示；
- 周期可见性属于轻量过滤功能，第一版保留：默认全部周期显示，也可改为仅当前周期或指定周期；
- 画线层与行情层解耦，数据刷新不改变已有图形。

## 8. Volume Profile 与筹码模型

### 8.1 可视区 Volume Profile

- 输入：当前可视范围内的逐笔或分钟 OHLCV；
- 横轴缩放/平移后异步重算；
- 价格分箱默认 48 档，可按最小变动价位或像素密度调整；
- 显示总量，并在数据允许时拆分主动买/卖或上涨/下跌近似量；
- 标识 POC、VAH、VAL；
- Value Area 默认覆盖总成交量的 70%，参数可调。

### 8.2 锚定区间 Volume Profile

- 用户在图上点选起止日期；
- 只统计区间内成交量；
- 区间锚点与画线一样以日期保存；
- 切换普通/Log 价格轴时统计区间不变，只改变价格方向的视觉投影。

### 8.3 筹码成本分布

- 单独开关和单独图例；
- 明确标注“基于历史成交与换手的估算”；
- 输出平均成本、获利比例、70%/90%成本区间；
- 不与可视区成交量分布共用颜色或名称；
- A 股优先，港股在数据完整性验证通过后启用。

## 9. 按日期追溯的预测与复盘日志

日志是本项目的核心数据，而不是临时文本框。日期是一级索引；同一天允许为不同股票、同一股票或同一周期建立多条记录，每条记录另有独立 ID。

### 9.1 活工作区与历史快照

- **主看板活工作区**：持续自动保存，用户可以随时新增、移动、修改、隐藏、擦除直线和自由画笔；图形一直保留，直到用户主动删除；
- **预测记录快照**：用户明确点击“保存预测”时，冻结当时的 Markdown、画线、自由笔迹、指标、坐标模式、可视范围、数据截止时间和 PNG；
- 保存预测以后继续修改主看板，不会改变已经冻结的记录；
- 更新某条历史预测会产生新 revision，旧 revision 不被覆盖；
- 从历史记录打开图形时提供三种方式：只读预览、复制到当前工作区、用快照替换当前工作区；
- 主看板删除图形只影响活工作区，不影响任何历史快照。
- 同一股票支持多个命名工作区，例如“主分析”“长期趋势”“短线计划”；工作区之间的图形、指标和可视范围相互独立。

### 9.2 保存内容

- 记录日期 `dateKey`，按 Asia/Shanghai 自然日归档；
- 创建时间、最后修订时间和行情数据截止时间；
- 股票代码、名称、市场和分析周期；
- 标题、自由文本/Markdown 笔记、标签；
- 核心判断与理由；
- 看多/基准/看空三种情景；
- 触发条件、失效条件、目标价格和目标日期；
- 主观置信度；
- 当时的画线、指标参数、坐标模式和可视范围；
- 自动生成的高清图表快照；
- 后续结果：待验证、部分符合、命中、失效；
- 复盘结论与下次改进。

### 9.3 历史完整性

- 首次保存形成不可覆盖的版本 `v1`；
- 后续编辑生成 `v2/v3...`，不静默篡改历史判断；
- 每个版本保留文字、图形快照、截图和数据截止时间；
- 支持“以当日视角查看”：行情只显示到记录时的数据截止点，减少后视偏差；
- 支持对比“当时预测”和“后来实际走势”；
- 用户可以自由加载任一记录或任一 revision；
- 删除记录先进入回收站，可恢复；
- 回收站支持删除单个 revision、删除整条记录或永久清空，永久删除前展示影响范围并要求确认。

### 9.4 检索与界面

- 日历视图：按日期显示当日记录数量和状态；
- 时间线视图：从最近记录向前追溯；
- 按股票、日期范围、标签、周期、结果筛选；
- 图表右侧使用可收起抽屉，不永久压缩主画布；
- 快捷键打开“今日记录”，保存时自动绑定当前股票与图表状态；
- 点击历史记录可恢复当时布局，也可只打开截图而不改变当前画布。
- 第一版每条记录绑定一个个股；同一天可以保存该个股的多次分析，也可以保存多个个股的独立记录。

### 9.5 本地存储与备份

- SQLite 是日志、版本和索引的本地事实来源；
- 图表截图与图形快照保存在本地 `data/journal/`；
- 单条记录可导出为独立目录：`record.md`、`chart.png`、`drawings.json`、`chart-state.json`；
- `record.md` 使用 YAML front matter 保存日期、股票、周期、版本、数据截止时间和标签，正文保持标准 Markdown；
- 支持一键导出项目 ZIP：全部 Markdown、PNG、画线快照、附件、manifest 与 SHA-256 校验清单；
- 支持从导出包恢复；
- 导入采用版本化 schema；未知扩展字段原样保留，避免导入导出造成信息丢失；
- 每日自动生成一份增量/完整可恢复备份，轮换保留最近 30 份；
- 不需要登录、云端账户或外部数据库。

## 10. 技术架构

### 10.1 前端

- TypeScript；
- React；
- Vite；
- Lightweight Charts 作为基础行情渲染层；
- 标准金融时间轴负责日期缩放和未来空白区；
- 内置/扩展价格刻度实现普通、Log 与百分比纵轴；
- Series/Panes Primitives 实现 Volume Profile 和画线覆盖层；
- Zustand 或等价轻状态容器管理布局、选股、绘图和坐标模式；
- IndexedDB 保存临时 UI 状态；正式画线与日志提交给本地后端保存。

正式开发前先验证普通/Log 价格轴下画线、Profile、价格标签和截图是否完全对齐。

### 10.2 后端

- Python + FastAPI；
- 行情 Provider Adapter，避免将页面绑定到单一免费接口；
- SQLite 保存元数据与用户配置；
- SQLite 以追加版本方式保存研究日志和画线记录；
- Parquet 保存分钟/日线行情；
- REST 获取历史数据；
- WebSocket 或短轮询更新当前行情；
- 后端统一执行代码规范化、交易日历、复权和周期聚合。

### 10.3 行情接口抽象

```ts
interface MarketDataProvider {
  resolveSymbol(input: string): Promise<Instrument>;
  getBars(request: BarsRequest): Promise<Bar[]>;
  getQuote(symbol: SymbolKey): Promise<Quote>;
  getTrades?(request: TradesRequest): Promise<Trade[]>;
}
```

首个适配器面向个人研究用免费数据；后续可替换为正式授权数据而不修改图表层。

## 14. 第一版验收标准

1. 主图在 1440×900 桌面视口中至少占内容区域高度的 58%。
2. 横纵轴默认字号不低于 15px，Profile 标签不低于 14px。
3. 可连续缩放到单屏约 20 根至 2,000 根日 K，操作不中断。
4. 最新 K 线右侧可扩展到至少一年后的空白日期。
5. 趋势线可以跨越已有数据区与未来空白区。
6. 普通/Log 价格轴切换后，所有锚点仍对应相同日期和价格。
7. Log 价格轴使用等比例刻度，纵轴标签仍显示真实价格。
8. 主图、VOL、MACD、十字光标完全同步。
9. 可视区 Profile 在平移/缩放停止后更新，并标出 POC/VAH/VAL。
10. 画线刷新页面后仍可恢复。
11. 截图导出包含 K 线、画线、Profile、坐标和指标。
12. 用户可一键进入无多余标记的纯净分析模式。
13. 用户可按日期找到当天的全部预测，并恢复当时的截图与画线状态。
14. 修改历史预测会生成新版本，旧版本仍可查看。
15. 日志可以完整导出和恢复，不依赖账户或云服务。
16. 同一天可保存任意多条独立记录，并可按日期完整检索。
17. 主看板中的直线和自由笔迹可编辑、擦除和撤销，历史快照不受影响。
18. 单条记录可导出为可读 Markdown 与配套 PNG/JSON，项目可整体导入导出。
19. 同一股票支持多个命名工作区，图形、指标和可视范围相互独立。
20. 图形默认跨周期显示，并可切换为仅当前周期或指定周期。
21. 历史记录可加载、移入回收站、恢复和永久删除。
22. A 股首次打开使用前复权，切换复权模式不会丢失原始画线数据。
23. 系统每日自动备份并保留最近 30 份，任一备份均可恢复。

## 15. 风险与预先决策

| 风险 | 处理方式 |
|---|---|
| 免费分钟数据历史短 | 本地增量归档；Provider 可替换 |
| 港股免费行情延时 | 界面明确显示延时与数据时间 |
| Log 价格轴下 Profile/画线出现像素错位 | P0 同时验证价格转换、分箱、标签和截图；必要时统一由同一价格转换器驱动 |
| 大字体导致标签碰撞 | 减少刻度密度、分层避让，不缩小到下限以下 |
| Profile 重算阻塞 UI | Web Worker、可视范围缓存、防抖更新 |
| 分钟 OHLCV 无法精确还原价位成交 | 标注“分钟估算”；逐笔数据可用时自动升级 |
| 图形在多周期切换时出现日期缺口 | 锚点保留真实 timestamp，并定义最近交易点吸附策略 |
| 历史预测被后续编辑覆盖 | 采用追加版本、自动截图和数据截止时间 |
| 本机数据丢失 | 一键导出 ZIP，并在后续加入可配置的自动备份目录 |
| 自由画笔点数过多影响性能 | Pointer 采样限频、RDP 路径简化、分段缓存和视口裁剪 |
| 导入旧版本包时 schema 变化 | manifest 版本号、迁移器、未知字段透传和导入前校验 |
