# P4 用户验收单

> 验收版本：`0.5.0`

- [ ] 水平线、趋势线、向右射线、平行通道、矩形和文本可在主图创建。
- [ ] 自由画笔与半透明荧光笔支持鼠标/触控笔Pointer事件。
- [ ] 选择工具可选中并拖动画线对象。
- [ ] 新建画线后自动进入编辑状态；水平线可直接上下拖动微调。
- [ ] 趋势线、射线等双锚点图形显示两个端点，任一端点均可独立拖动。
- [ ] 选中对象后可精确输入首锚点日期、价格、文字和颜色。
- [ ] 价格输入框支持滚轮按 `0.01` 微调，按住 Shift 时按 `0.10` 调整。
- [ ] 点击“完成画线”后对象才锁定；重新选中可“解锁编辑”。
- [ ] 对象可锁定、复制、隐藏、删除。
- [ ] 橡皮擦点击对象会删除完整图形。
- [ ] 撤销/重做可恢复至少最近80次操作。
- [ ] 关闭/刷新页面后画线仍恢复。
- [ ] 主分析/长期趋势/短线计划三个命名工作区相互隔离。
- [ ] 图形默认全部周期显示，可设置为仅当前周期。
- [ ] 弱/强吸附会吸附到最近K线OHLC，亦可关闭。
- [ ] 切换普通/Log和周期后锚点仍使用原始日期/价格语义。
- [ ] 行情刷新不会删除或移动画线数据。

结论： [ ] 通过  [ ] 有条件通过  [ ] 不通过
