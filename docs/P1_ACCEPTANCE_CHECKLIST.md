# P1 用户验收单

> 验收版本：`0.2.0`
> 验收分支：`feat/p1-visual-foundation`
> P1目标：视觉骨架、本地前后端工程、一键启动与多字号适配

## 1. 启动与关闭

- [ ] 在项目目录执行 `npm run app`，API和Vite均正常启动。
- [ ] Terminal显示看板地址 `http://127.0.0.1:4173/`。
- [ ] Terminal显示API地址 `http://127.0.0.1:8000`。
- [ ] 浏览器可以打开看板，底栏显示“本地API · 0.2.0-p1”。
- [ ] 在服务运行时再次执行 `npm run app`，提示复用现有API和看板，不出现端口冲突。
- [ ] 在首次运行服务的Terminal按 `Ctrl+C`，该命令启动的前后端一起结束。

## 2. P1工程骨架

- [ ] 打开 `http://127.0.0.1:8000/api/health`，返回 `status: ok`。
- [ ] 打开 `http://127.0.0.1:8000/api/demo/snapshot/001280`，返回样例标的信息。
- [ ] 打开 `http://127.0.0.1:8000/docs`，可以看到FastAPI接口文档。
- [ ] API未启动、只运行前端时，看板显示“样例降级模式”，主图仍可查看。

## 3. 视觉与字号

- [ ] 顶部阶段标识为“P1”。
- [ ] 首次打开默认选择“大”字号。
- [ ] “标准 / 大 / 特大”三档均可切换。
- [ ] 刷新页面后仍保留上次选择的字号。
- [ ] 字号变化时，横轴、纵轴价格和分时图坐标同步变化。
- [ ] 1440×900下没有页面级横向或纵向滚动条。
- [ ] 1920×1080下主画布充分利用宽度，研究日志没有遮挡坐标轴。
- [ ] 初始画布没有预设水平线、趋势线或分析文字。

## 4. P0能力回归

- [ ] 普通价格轴与Log价格轴可以往返切换。
- [ ] K线支持滚轮缩放和拖动平移。
- [ ] 成交量分布可以显示和隐藏。
- [ ] 左侧工具悬浮时显示工具名称。
- [ ] 日历可以定位2026-08-03、2026-07-28等有记录日期。
- [ ] 点击真实日K后进入对应日期的样例分时图。
- [ ] 分时横轴显示上海交易时间，并可返回日K。
- [ ] 研究日志可以收起、展开，并可添加当前会话内的Markdown记录。

## 5. P1只验收入口、不验收行为的项目

以下项目点击后应显示明确的后续里程碑提示；它们不是P1功能失败：

| 入口 | P1预期行为 | 正式实现阶段 |
|---|---|---|
| 1/5/15/30/60分钟、周K、月K | 提示属于P2，画布继续保持日K，不假装切换数据 | P2 |
| 不复权/后复权 | 提示属于P2，样例继续使用前复权 | P2 |
| 输入其他A/H股票代码 | 只展示搜索骨架 | P2 |
| 趋势线、水平线、自由画笔、矩形、橡皮擦 | 工具可选中并提示属于P4，不在画布创建对象 | P4 |
| 撤销/重做、命名工作区持久化 | 只保留信息架构入口 | P4 |
| 正式动态Volume Profile、POC/VAH/VAL | 当前为固定视觉样例 | P5 |
| 历史快照、加载、版本、回收站 | 显示P6提示 | P6 |
| 高清截图导出 | 显示P7提示 | P7 |

## 6. P1不通过条件

出现下列任一情况时，P1应退回修复：

- [ ] `npm run app`在端口空闲时启动失败。
- [ ] 重复运行产生端口占用错误，而不是复用提示。
- [ ] 看板连接API后仍长期显示“样例降级模式”。
- [ ] 三档字号无法切换或刷新后丢失。
- [ ] 1440×900或1920×1080出现主要控件重叠、裁切或页面级溢出。
- [ ] 普通/Log、日历、日K/分时等P0回归功能失效。
- [ ] P2/P4/P5/P6/P7入口把占位效果描述成已经实现的正式功能。

## 7. 验收结论

- [ ] **通过**：以上P1范围全部通过，允许合并到 `main` 并创建 `v0.2.0-p1`。
- [ ] **有条件通过**：记录问题，但不影响进入P2。
- [ ] **不通过**：保留功能分支，完成修复后重新验收。
